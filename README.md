Un timer Pomodoro elegante e minimale progettato per massimizzare la produttività riducendo le distrazioni.

## ✨ Caratteristiche
- **Interfaccia Dark Mode**: Design riposante per lunghe sessioni di studio.
- **Personalizzazione**: Regola i tempi di lavoro e pausa secondo le tue esigenze.
- **Integrazione Estetica**: Un orologio pulito con animazioni fluide.
- **Suoni Notifica**: Avvisi discreti per il cambio sessione.

## 🛠️ Tecnologie
- Vanilla HTML5
- CSS3 (Custom Properties / Flexbox)
- JavaScript ES6+
